# Campus Voice Outcomes

- Build the calm, flat, monochrome Campus Voice UI using the supplied DESIGN.md tokens: warm gray canvas, white rounded panel, thin borders, no heavy shadows, soft radii, light typography, and status-only color.
- Provide a responsive app shell with a fixed desktop sidebar that collapses into a mobile top bar, including workspace branding, search, role-aware navigation, active states, and a role switcher for Student, Faculty/Staff, and Admin.
- Provide Student views for Home, Updates, Calendar, Saved, and Profile, including urgent banner, recent updates, upcoming deadlines, category filters, grid/list toggle, Month/Week/Agenda calendar modes, saved items, profile/preferences, and notifications with All/Unread/Urgent filters.
- Provide Faculty/Staff views for Home, Create, My Updates, and Analytics, including a step-by-step create flow, status filters for Draft/Pending/Published/Rejected/Scheduled/Archived, and views/reach/read-status analytics.
- Provide Admin views for Home, Updates, Users, Setup, Analytics, and Logs & Settings, including approval queue/status filters, user role table, category/audience setup, analytics, audit logs, notification channels, and approval rules.
- Reuse accessible shared primitives for buttons, chips, cards, tabs, inputs, avatars, page headers, toolbars, update cards, tables, and timeline/calendar rows.
- Include local interactions for role switching, navigation, search/filtering, grid/list mode, bookmarks, read state, notifications, calendar mode, and create-flow progression without adding backend behavior.
- Add route manifest, project metadata, responsive styling, visible hover/focus/disabled states, and verify with diagnostics plus a production build.
